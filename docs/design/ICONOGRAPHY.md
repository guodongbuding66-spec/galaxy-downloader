# Iconography

## Principles

Icons support recognition; they do not replace essential labels in primary workflows.

- Prefer one consistent outline family per surface.
- Keep stroke weight visually consistent at a given size.
- Do not mix emoji, filled glyphs, text symbols and custom icons for equivalent actions.
- Brand marks are separate from functional icons.
- Status icons must be paired with text or another non-color cue.

## Sizes

- 16 px: compact table/list metadata.
- 18–20 px: standard control/action icon.
- 24 px: navigation/sidebar or empty-state supporting icon.
- 32+ px: rare product/feature illustration only.

## Required semantic set

The Desktop/Web icon vocabulary should cover:

- download, upload, pause, resume, retry, cancel
- queue, history, library, collection, bookmark
- video, audio, image, document, subtitle
- transcript, microphone, speaker, AI
- course, lesson, note, flashcard
- reader/book, music
- subscription/RSS
- transfer, link, QR, Telegram, torrent
- plugin, settings, tools
- search, filter, sort, refresh
- folder, file, open external
- warning, success, error, info
- copy, edit, delete, more

## Button usage

- Primary actions: icon + visible verb where space permits.
- Secondary toolbar actions may be icon-only only when universally recognizable and accompanied by a tooltip/accessibility label.
- Destructive actions must not rely on a trash icon alone in confirmation dialogs.
- Avoid icons whose meaning changes by context without a label.

## State

- Default: secondary text color.
- Hover/focus: primary text or accent depending on control hierarchy.
- Disabled: subtle text color; cursor and focus behavior must also indicate disabled state.
- Active navigation: accent may be used alongside a persistent shape/border/text state.

## Custom Galaxy mark

The Galaxy brand mark may use violet + cyan. Functional UI should not repeat the brand mark as a generic download/status icon.

## Review checklist

- Same action uses the same icon everywhere.
- Icon-only controls have tooltip/accessibility text.
- Icons remain legible at 100% and common Windows scaling levels.
- No decorative icon is mistaken for a control.
- Status meaning remains understandable without color.
