# Galaxy Local Engine UI v1.6.1

## Canonical Windows surface

`GalaxyLocalEngine.exe` **itself is the desktop application**. It is built from the Python/Tk engine entrypoint with PyInstaller and opens the native Windows workbench directly.

The HTML / Headless Dashboard is a separate optional surface for browser/headless workflows. It is not the default GalaxyLocalEngine.exe UI and is not used as a wrapper around the executable.

## Native redesign

- Neutral graphite desktop surfaces with one blue action accent.
- Larger Segoe UI type scale for common 100–125% Windows scaling.
- Native layout prioritizes Quick Download / current task on the left and queue/runtime context on the right.
- Existing download, queue, recovery, tools and hook behavior is preserved; only native composition and visual tokens are replaced.
- Buttons expose hover, pressed and keyboard-focus feedback while keeping the 44px interaction target contract.
- Windows EXE icon is generated by `generate_icon.py` and embedded by PyInstaller using `--icon local-engine/GalaxyLocalEngine.ico`.
- The title-bar mark uses the same `G + download arrow` visual language as the packaged EXE icon.

## UI Skills applied

Project-scoped guidance remains under `.agents/skills/`:
- `interface-design`
- `frontend-design`
- `better-ui`

The native workbench follows the project design system in `.interface-design/system.md`: one focal workflow, restrained surfaces, readable hierarchy, minimal decorative styling and explicit interaction states.

## Windows package layout

The official release workflow produces one canonical application executable:

```text
GalaxyLocalEngine.exe = native Tk/Python download engine + desktop UI
```

FFmpeg and yt-dlp remain bundled beside it as verified runtime dependencies. There is no `GalaxyLocalEngineBackend.exe` indirection in the official V1.6.1 release package.

## Version correction

The incorrect browser-launcher experiment was limited to the earlier V1.6 packaging attempt. V1.6.1 / Engine 0.15.1 restores the intended native executable architecture and rebuilds the actual EXE icon and desktop interface.
