Galaxy Local Engine 使用说明（Windows）
======================================

用途
----
Galaxy Local Engine 用于在本机调用 yt-dlp + FFmpeg 下载和合并视频。
适合 YouTube、B站、小红书、快手、Dailymotion 等存在登录、反爬或 IP 绑定限制的平台。
视频、Cookie 和 FFmpeg 处理都留在本机，不上传 Galaxy 服务器。

一、首次安装
------------
1. 从 Galaxy Downloader 网站点击“下载 / 更新 Galaxy Local Engine”。
2. 下载 GalaxyLocalEngine-Windows.zip。
3. 右键 ZIP → “全部解压”。不要直接在压缩包里面运行程序。
4. 打开解压后的文件夹，双击 install.cmd。
5. 安装器会自动：
   - 安装 / 更新 Galaxy Local Engine；
   - 下载并校验 FFmpeg；
   - 下载并校验官方 yt-dlp.exe；
   - 注册 galaxy-downloader:// 协议；
   - 启动 Galaxy Local Engine。
6. 安装成功后，Galaxy Local Engine 窗口顶部会显示当前版本号。

默认安装位置：
%LOCALAPPDATA%\GalaxyDownloader\LocalEngine

默认下载位置：
%USERPROFILE%\Downloads\Galaxy Downloader

二、在网站中使用
----------------
1. 在 Galaxy Downloader 网站解析视频。
2. 在“当前成品方案”中选择画质、音质、字幕和封面。
3. 保持 Galaxy Local Engine 正在运行。
4. 网站会自动检测本地引擎，正常状态应显示：
   “本地引擎已连接”。
5. 如平台需要登录状态，可选择：
   - Edge
   - Chrome
   - Firefox
6. 点击“按当前方案本机下载”。
7. 网站与 Galaxy Local Engine 会同步显示下载状态和进度。
8. 下载完成后可点击“打开下载文件夹”。

三、升级
--------
1. 再次点击网站上的“下载 / 更新 Galaxy Local Engine”。
2. 下载最新版 ZIP 并完整解压。
3. 双击新的 install.cmd。
4. 安装器会自动关闭旧版 Galaxy Local Engine，然后覆盖升级并重新启动。
5. 返回网站，确认显示新的版本号和“本地引擎已连接”。

四、如果网站显示“本地引擎未连接”
--------------------------------
请依次检查：
1. Galaxy Local Engine 是否正在运行。
2. 是否安装的是 v0.3.1 或更高版本。
3. 是否完整解压 ZIP 后运行了 install.cmd。
4. 刷新 Galaxy Downloader 网站。
5. 在浏览器地址栏打开：
   http://127.0.0.1:17836/health

如果能看到 JSON 状态，说明本地引擎通信服务已经启动。
如果打不开，请重新运行 install.cmd 或重新启动 Galaxy Local Engine。

五、登录状态 / Cookie
---------------------
当 YouTube、B站或其他平台需要登录时，可以在网站中选择 Edge / Chrome / Firefox 登录状态。
yt-dlp 会直接从本机浏览器配置中读取 Cookie；Cookie 不会上传 Galaxy 服务器。

如果读取 Cookie 失败：
1. 先在对应浏览器中正常登录目标网站；
2. 关闭可能锁定 Cookie 数据库的浏览器窗口后重试；
3. 或选择“不读取浏览器 Cookie”测试公开视频。

六、常见问题
------------
Q：需要管理员权限吗？
A：通常不需要。程序安装在当前 Windows 用户目录。

Q：为什么一定要完整解压？
A：install.cmd、install.ps1、GalaxyLocalEngine.exe 等文件需要位于同一个解压目录，直接在 ZIP 内运行可能导致安装失败。

Q：安装时为什么会联网？
A：安装器需要下载 FFmpeg 和官方 yt-dlp.exe，并进行 SHA-256 校验。

Q：本地引擎打开后显示 Waiting for a download job 正常吗？
A：正常。表示本地引擎已经启动并正在等待网站发送任务。新版网站检测成功后会显示“本地引擎已连接”。

Q：下载文件在哪里？
A：默认在：%USERPROFILE%\Downloads\Galaxy Downloader

七、卸载
--------
在安装包或安装目录中运行 uninstall.cmd。
