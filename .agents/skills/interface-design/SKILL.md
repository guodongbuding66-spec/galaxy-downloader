# Interface Design
Use for product interfaces, not marketing surfaces. Every view needs one focal point. Decide density, hierarchy, color temperature, spacing grid, elevation, typography and motion before implementation. Avoid generic dashboard defaults, card grids, excessive pills, decorative gradients, and arbitrary rounded containers. Prefer quiet layering, whitespace, weight and tonal shifts over lines and decoration. Preserve real product behavior and existing semantics.
