# Better UI
Polish through consistent radii, optical alignment, restrained shadows, precise borders and short interaction feedback. Use targeted property transitions rather than transition:all. Respect reduced motion. Keep hit targets usable and states legible. Press feedback may use scale(.96) with 150ms ease-out when appropriate; high-frequency desktop interactions should remain visually quiet.
